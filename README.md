# AnyDeck 🎉

**The party game about anything.** A "phone on your forehead" guessing game — like Heads Up — with one unfair advantage: **AI generates a playable deck about literally any topic in seconds.**

## Why this wins in a crowded market

Every forehead-game competitor ships a fixed catalog of decks. AnyDeck's moat:

1. **Infinite content** — type "Tunisian street food", "our office inside jokes", or "obscure Star Wars ships" and play it 10 seconds later. No competitor can match a deck catalog that writes itself.
2. **Underserved languages** — Heads Up is English-first. AnyDeck generates and ships decks in Arabic, French, and anything else. Party games are viral in exactly the markets big publishers ignore.
3. **Viral deck sharing** — decks travel as QR codes and paste-codes. Every custom deck a group makes recruits the next group.
4. **Monetization that scales with the differentiator** — AI generation costs money per use, which makes a subscription feel *fair* instead of greedy. Competitors selling static $1.99 packs can't structurally copy this.

## Gameplay

- Hold the phone on your forehead, screen facing your friends.
- Friends give clues; **tilt down = correct, tilt up = skip** (tap zones as accessible fallback).
- 60-second rounds (configurable), tick sounds in the last 5 seconds, haptics on every action.
- The play screen floods with the deck's color and shifts green/red as you tilt — you feel the game state without seeing the screen.
- Quick mode, pass-and-play multiplayer, and team mode with cross-round standings, confetti, and share cards.

## Project layout

```
anydeck/
  src/
    app/                 # expo-router screens (thin — routing + composition only)
    components/          # shared UI kit (AppText, BigButton, Confetti, ...)
    features/
      audio/             # expo-audio SFX (generated WAVs, silent-mode override)
      decks/             # deck types, bundled JSON data, storage, share codec, AI client
      economy/           # coins, daily challenge, entitlements, payment/ad seams
      game/              # engine (pure logic), tilt controls, match store
      haptics/           # settings-aware haptic helpers
      settings/          # persisted user settings context
      stats/             # local statistics
      theme/             # colors, accent themes, dark/light
    lib/                 # namespaced AsyncStorage JSON helpers
  assets/sounds/         # generated by scripts/generate-sounds.js
  scripts/generate-sounds.js
  server/                # AI deck generation API (deploy separately)
```

Architecture: screens are controllers, features own logic, engine is pure and testable. Decks are plain JSON — new categories ship without code changes (bundled, or later served remotely).

## Run it

```sh
npm install
npx expo start        # scan QR with Expo Go (sensors need a real phone)
```

Tilt controls need a physical device. In the simulator use the tap zones.

## AI deck generation (server)

The mobile app calls a tiny API so the AI key never ships in the binary. The server uses
**Gemini 2.5 Flash** over plain REST (zero dependencies) — a free-tier Google AI Studio key
is enough to launch.

```sh
cd server
# deploy to Vercel (or any Web-standard runtime) with GEMINI_API_KEY set
```

Then point the app at it:

```sh
# .env in the app root
EXPO_PUBLIC_ANYDECK_API_URL=https://your-deployment.vercel.app
```

The endpoint ships with input validation and a best-effort per-device/IP rate limit
(10 decks/hour). For serious volume, swap the in-memory limiter for Upstash Redis and
add entitlement checks (subscription receipt) before generating.

## Design system

- **No emoji, anywhere.** Lucide stroke icons via a curated, tree-shaken registry
  (`src/components/icon.tsx`). Deck icons are data (`deck.icon`), picked by the AI or the user.
- **Ink & amber.** Warm near-black neutrals, one confident amber accent with dark-on-amber
  CTAs, and 12 deck hues drawn from a single saturation family so the catalog reads curated.
- System font at heavy weights (the native-feel move), uppercase tracked labels for
  section headers, 18–26pt radii, 1px hairline borders on surfaces.
- Reduced-motion respected (confetti disables itself), all touchables 44pt+, every control
  carries an accessibility label.
